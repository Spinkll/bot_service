# Telegram Lead Generation Bot (Telegraf & TypeScript)

Масштабируемый Telegram-бот для сбора заявок на IT-услуги. Построен на базе **TypeScript**, **Telegraf (Scenes/Wizard)** и **Node.js**.

## 🌟 Возможности

- **Пошаговая анкета (Wizard Scene):**
  1. **Категория:** выбор направления с помощью Inline-кнопок («Веб-приложения», «Telegram-боты/Мини-аппы», «Автоматизация бизнеса», «Свой вариант / Консультация»).
  2. **Описание задачи:** приём текстового описания задачи (с защитой от стикеров, фото и пустых сообщений).
  3. **Бюджет:** выбор вилки стоимости через Inline-кнопки («До $500», «$500 - $1000», «Больше $1000», «Нужна оценка»).
  4. **Контактные данные:** нативная кнопка «Поделиться контактом» либо ввод телефона/@username сообщением.
  5. **Финал:** подтверждение клиенту с удалением клавиатуры и мгновенная отправка заявки в админский чат/канал.
- **Глобальная отмена (`/cancel`):** работает на любом шаге опроса и вне его.
- **Изолированная конфигурация (`src/config/survey.ts`):** все тексты сообщений, кнопки, категории и шаблоны вынесены отдельно. Можно менять форму без изменения логики сцен.
- **Валидация типов:** защита от спама медиафайлами и стикерами на шагах, ожидающих текст или нажатие кнопок.
- **Уведомление администратора:** HTML-верстка заявки с ссылкой на профиль клиента и экранированием спецсимволов.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта (скопируйте из `.env.example`):
```bash
cp .env.example .env
```

Заполните переменные:
- `BOT_TOKEN`: токен вашего бота, полученный у [@BotFather](https://t.me/BotFather).
- `ADMIN_CHAT_ID`: Telegram ID чата, группы или канала, куда бот будет присылать заявки (узнать свой ID можно через бота [@userinfobot](https://t.me/userinfobot), для каналов/групп ID обычно начинается с `-100`).

> ⚠️ **Важно:** бот должен быть предварительно добавлен в группу/канал администратора с правом отправки сообщений.

### 3. Запуск в режиме разработки (с автоперезагрузкой)
```bash
npm run dev
```

### 4. Сборка и запуск в production
```bash
npm run build
npm start
```
